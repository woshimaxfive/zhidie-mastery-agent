# 知迭（Zhidie MasteryAgent）

知迭是一个以“掌握证据”为核心的个性化学习 Agent。它根据学习者的真实作答进行诊断，选择适当的渐进引导，通过迁移任务验证独立掌握，并据此决定下一步学习动作。

当前仓库处于 v0.1 需求与设计阶段。第一条可运行纵向切片聚焦 Python `range()`，但产品架构不会绑定单一知识点。

## 当前目标

跑通并验证以下真实闭环：

```text
诊断 → 引导 → 尝试 → 迁移验证 → 掌握证据更新 → 下一步决策
```
